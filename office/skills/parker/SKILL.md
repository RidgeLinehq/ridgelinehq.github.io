   "predict: <number>" for the next run.

- Two subject patterns per week, alternated, tagged.
- Leads with angle equals Qualified leads with an email and no touches (up to today's cap x 2)
  plus follow-ups due, before Echo starts; a Qualified lead with an email and no angle is
  written in the run doc as a miss (push-week target; run notes 2026-10-22, Parker: 2 angles

  angle.subjectPattern A or B, alternating by lead order (03-parker CONTEXT, step 4; run notes
  2026-10-22, Parker: Ridgeback pattern A, Britton pattern B).

  check) and never calls a directory list "Google" or "AI" (scoring.md "Two doors"; run notes
